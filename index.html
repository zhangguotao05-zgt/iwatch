iwatch

基于 SF32LB586VDD36 的自研智能手表项目，当前阶段以离线界面、触摸/表冠交互、运动传感、振动反馈和心率/血氧采集为方向。主控采用芯片直接贴装，外壳自行设计。

本仓库保存硬件工程、BOM、设计评估、生成脚本和可编译的手表 UI 固件基线。当前尚未完成佩戴版 PCB 布局布线、整机装配及实物验证，没有可直接生产的 Gerber；固件目前是开发板验证版本，并非完整产品固件。

版本状态

  • 已保存的电路基线是 原理图 v0.3，主控 SF32LB586VDD36，采用原开发套装的屏幕转接接口。
  • 2026-09-11 的记录包含 153 个器件/测试点位置，以及当时原理图 DRC 的 0 致命错误、0 错误、0 警告。这些结果不能替代实际布线和硬件测试。
  • 主板 PCB1 的未布线准备稿当时保存在在线 EDA 私人工程中，本仓库没有该主板 PCB 文件。连接器封装工程自带的 PCB 预览页只是封装预览。
  • 当前实物 UI 验证使用 390×450 QSPI AMOLED 开发模组，CO5300 + FT6146，已经点亮。佩戴版另有 CWS05 / C50396528（CO5300AF + CST820）修订评估；它的 24 针、1.8 V 数字接口不能直接接原版 3.3 V 接口，两者不能混用驱动和电源定义。
  • 佩戴版拟采用普通阻容优先评估英制 0201 的策略；复位/下载按键改测试接点，Home/唤醒拟并入表冠按压。
  • 电池、马达、表冠、板框、屏幕配对连接器和部分供电定义仍需确定。联网、官方微信/支付宝等暂不属于当前阶段。

注意版本体系：文件名中的“方案/BOM v0.4”是早期规划文档版本，不代表原理图已经升级到 v0.4。历史方案中的模组及旧屏幕建议，以最新原理图说明和修订评估为准。

项目现名为 iwatch。已归档的 v0.1–v0.3 电路文件和 ZIP 工程包继续保留原来的 HealthWatch-SF58 文件名及校验值；说明文档改为 HTML 后，目录中的校验清单同步指向当前 HTML。后续新版本使用 iwatch 名称。

固件 D01–D06 已通过主机、双工具链和开发板验收。D07 v2 已以 967483d 为批准基线；A0 的字符契约、确定性子集、双工具链预算解析、受控 SDK 补丁和 25 点主机 OOM 注入已经通过，尚待采集替换前通知页实屏基线。当前 GCC main 为 5,745,568 B，占 6 MiB 槽的 91.323%；A1 尚未替换字体，也没有产生新可刷镜像。
