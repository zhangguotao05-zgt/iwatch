# iwatch

基于 **SF32LB586VDD36** 的自研智能手表项目，当前阶段以离线界面、触摸/表冠交互、运动传感、振动反馈和心率/血氧采集为方向。主控采用芯片直接贴装，外壳自行设计。

本仓库保存硬件工程、BOM、设计评估、生成脚本和可编译的手表 UI 固件基线。**当前尚未完成佩戴版 PCB 布局布线、整机装配及实物验证，没有可直接生产的 Gerber；固件目前是开发板验证版本，并非完整产品固件。**

## 版本状态

- 已保存的电路基线是 **原理图 v0.3**，主控 SF32LB586VDD36，采用原开发套装的屏幕转接接口。
- 2026-09-11 的记录包含 153 个器件/测试点位置，以及当时原理图 DRC 的 0 致命错误、0 错误、0 警告。这些结果不能替代实际布线和硬件测试。
- 主板 PCB1 的未布线准备稿当时保存在在线 EDA 私人工程中，本仓库**没有该主板 PCB 文件**。连接器封装工程自带的 PCB 预览页只是封装预览。
- 最新拟选屏幕为 **亚特联 CWS05 / C50396528，390×450 QSPI AMOLED，CO5300AF + CST820**。其 24 针、1.8 V 数字接口不能直接接原版 3.3 V 显示/触摸接口。
- 佩戴版拟采用普通阻容优先评估英制 **0201** 的策略；复位/下载按键改测试接点，Home/唤醒拟并入表冠按压。
- 电池、马达、表冠、板框、屏幕配对连接器和部分供电定义仍需确定。联网、官方微信/支付宝等暂不属于当前阶段。

**注意版本体系：**文件名中的“方案/BOM v0.4”是早期规划文档版本，不代表原理图已经升级到 v0.4。历史方案中的模组及旧屏幕建议，以最新原理图说明和修订评估为准。

项目现名为 **iwatch**。已归档的 v0.1–v0.3 硬件文件继续保留原来的 `HealthWatch-SF58` 文件名和校验值，避免破坏已有工程包；后续新版本使用 `iwatch` 名称。

## 目录

```text
hardware/       原理图、封装、BOM、审阅图、历史方案及最新评估
firmware/       手表应用源码、项目专用板级配置和构建脚本
tools/          原理图/封装/评估/BOM 的生成与校核脚本
docs/           项目状态、资料来源及复现说明
```

导入工程时，在立创 EDA 专业版选择“文件 → 导入 → 嘉立创 EDA（专业版）”，使用 `.epro` 文件。优先阅读对应目录的说明，再修改电路。

Python 脚本依赖见 [requirements.txt](requirements.txt)，使用限制和外部输入见 [复现说明](docs/复现说明.md)。厂商资料与第三方来源见 [资料来源](docs/资料来源.md)。
