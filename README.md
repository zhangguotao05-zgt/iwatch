# iwatch

基于 SF32LB58、RT-Thread 和 LVGL 9.4 的智能手表项目。当前硬件验证平台为 SF32LB58-DevKit-LCD A128R32N1，显示模组为 390×450 QSPI AMOLED（CO5300 + FT6146）；自研原理图选型为 SF32LB586VDD36。
