字体注册表与所有权

实现位于 gui_core/iw_font.c 与 iw_font_port.c。注册表为静态数组，共 11 项：16、18、20、22、24、26、28、30、64、80、96 px。16/18/24/28 标为兼容字号，新增组件使用主题定义的七个角色。普通字号保留 16 个字形缓存条目，大号 64/80/96 初始为 4 个，按批准预算控制 PSRAM 占用。

接口契约
iw_font_initlv_init 后由 app_watch 绑定 GUI owner，一次注册全局 OOM 钩子，不分配字体。同一源数据与长度重复初始化成功，不允许运行中换源。源字节必须保持有效。
iw_font_acquire零初始化句柄，按显式 ID 延迟创建。相同 ID 共享字体，增加引用不再分配；未初始化、错误线程、非法参数、故障锁存、计数上限及创建失败返回不同结果。
iw_font_release调用者先删除全部引用字体的控件，再释放句柄。句柄不可复制或修改，每次 acquire 对应一次 release；释放成功将句柄清零，重复释放空句柄成功。仅减少引用，不在这里销毁字形。
iw_font_collect仅 GUI 主循环、LVGL 回调之外调用。零引用字体等待 GPU/LCD 空闲后才销毁；忙时返回 false 并保持字形有效。
代际与上限指针、ID、generation 一同验证，拒绝上一生命周期的失效句柄。单字号引用达到 UINT16_MAX 或 generation 无法再增长时先返回 LIMIT，不改变状态。不保证识别违反契约复制的同代句柄。

通知页每个字号只持有一个句柄；页面内控件借用其只读字体指针。停止顺序保留为回调/定时器与插件停止、控件删除、页面字体引用释放，再由统一服务在安全点回收。主循环每 250 ms 采样一次，进入深度等待时不承诺该频率。

故障锁存与应急层

生产 TinyTTF/EPIC 回调只增加饱和计数并锁存 pending，不打印、不删对象、不释放资源。pending 时拒绝新的字体 acquire。故障处理仍在 GUI 安全点等待渲染空闲，然后执行幂等页面停止，统一 collect 确认无存活字体后才能清除故障并显示预创建应急层。

应急层继续使用独立内置位图字体；不依赖本服务重新分配。按键返回、重复退出、重新进入保持 A1 约定。确认接口不会强制销毁仍有引用的字体，也不能在其他页面仍持有字体时清除全局故障。B 当前只有通知页一个动态字体使用方；C/D 及后续路由必须在安全点释放全部相关页面使用方，不能把该确认接口当作跨页面自动回收器。

LV_USE_OS_NONE 编译约束和缓存同步均保留；永久 GPU/LCD 忙导致的故障恢复期限、有限重试与受控重启仍属于 D16。

只读主题

iw_theme_get() 返回唯一静态只读主题；iw_theme_effects() 按 Q0/Q1、是否减弱动态效果选择只读参数，无堆分配或可变全局样式。非法质量等级返回空指针，非法字体角色返回 0，不静默替代字号。

内存计量

iw_font_stat 保留 A1 的四行诊断，并增加注册字号、总引用、存活峰值、大字缓存条目以及主堆/字形池峰值增量。字体文件56,804 B、内置位图字体、运行时主堆与预留160,000 B的PSRAM字形池分别计量。

每轮从零引用进入时保存两类堆已用值；累积峰值使用系统全局堆高水位减基线的保守上界，包含其他GUI分配，不是字体独占内存，也不是同时峰值。GUI发布的计数快照在短临界区内复制；串口读取当前堆值用于稳定桌面样本，两类堆不是硬件原子联合采样。

验收仍比较重复退出后的主堆和PSRAM各自稳定样本，并检查是否持续增长。残留≤32 KiB不能替代趋势检查；主机模拟的PSRAM统计只能验证通道，不能代替实物预算。
