两类缺陷及修复边界

现象证据与原因处理
进入表盘时停机rt_free 检出重复释放；主机长通知字距缓存淘汰在 ASan 下复现。be31c1b 关闭字距缓存。后续原始日志记录两次正常进入，没有再次断言；这不代表文字显示通过。
中文笔画错乱，部分标题正常TinyTTF 在 PSRAM 生成 A8 像素，字体 handler 没有 flush 回调；EPIC 标签层未设置 data_size。首次混合按几何尺寸清理缓存，后续混合按 0 B 清理，GPU 可读到旧内容。39c8607 将标签前景层长度设置为 mask_stride * glyph_height，覆盖行填充。保持原有 GPU、缓存容量及页面行为。

渲染修复纳入原受控 SDK 补丁，白名单由 11 个文件扩展为 12 个，新增 middleware/lvgl/lv_drivers_v9/sifli/lv_draw_epic_label.c。固定 SDK 保持干净；派生 SDK、补丁文件及文件哈希均由构建身份验证。

主机验证方法与结果

原淘汰测试只查询字形描述，没有验证像素。本轮补上缓存字形与无缓存重新光栅化的逐行比较，并直接编译生产 _draw_epic_letter 及 drv_epic_cont_blend，仅替换硬件边界。测试模型维护独立的 CPU/GPU 像素视图，按生产代码实际请求的清理范围同步。
