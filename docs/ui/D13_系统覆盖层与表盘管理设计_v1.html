现有基础与边界

D12 以审批基线 62f0686、固件源码 9fa21c8 收口。D08 已有页面作用域、8 级导航和 6 项历史；D09 已识别双键、旋转注入与水锁长按；D10 提供 390×450 的主题、字体和正式页面；D12 提供会话内闹钟及提醒快照。当前 IW_PAGE_CONTROL_CENTER 等页面 ID 已预留，但多数描述符仍是 RESERVED／OVERLAY，不能把 ID 存在当作页面可用。控制中心和切换器的键意图也尚未接到产品路由。

本任务只显示本机已实现且可读回的状态：亮度、有效时钟、活动计时器、闹钟及提醒、已运行 App 的有界历史。没有联网、电池量、支付、健康读数或佩戴检测的真实 Provider 时，不画可交互的假开关或假读数。D13 数据仅在会话内有效；断电保存、flash1 FAL 修复归 D15。#8 性能、#10 显示异常保持独立。

页面和数据契约

页面数据与动作空态及退出
控制中心读取 D06 亮度 desired/applied；允许调节亮度和进入水锁。没有对应能力的无线、静音等控制不出现。亮度驱动不可用时显示状态并禁用调节；Back／Home 回精确来源。
通知列表／详情只投影 D12 未确认提醒账本，使用 source、ID、occurrence 组成稳定选择键；详情沿用服务 ACK／稍后命令，不缓存可变指针。0 项显示“暂无通知”；记录被别处确认或合并后显示已变化并安全返回。HELD 闹钟可查看和确认，不自动响、不再稍后。
智能叠放固定卡片：时钟、最近活动计时器、下一次已启用闹钟。每张卡片从现有快照取值；选择时再次校验版本。无可信时间或无对应业务时显示明确空态；不生成演示健康数据。
App 切换器使用 D08 六项有界历史的稳定 App／页面 ID；缩略图可缺省，图标和名称回退。选择前检查路由 READY 及当前能力。无历史时回应用列表；被驱逐或不可用项不可启动旧控件。
输入锁／水锁进入时由 GUI owner 取消当前按压、清空候选手势，再切换 D09 上下文。水锁只允许 KEY1 规定的长按解锁，退出后等待真实松手才重新接收触摸。锁页必须有实体键可达的退出路径；重启、字体故障或显示恢复不得留下无法退出的锁。
表盘选择／编辑先提供数字表盘与“模块·本地”两个项目自有方案；候选配置放页面草稿，确认后更新会话目标，取消无副作用。无资源时回退数字表盘；不显示“已保存到设备”之类持久化文案。

通知中心不是第二本提醒账本；最多投影现有 24 条，排序与服务一致。页面只保存值类型键与自身滚动偏移。命令受理、终态和 ACK 仍走 D05 账本；离页后结果不得回写旧 generation 的 GUI 对象。叠放卡片和切换器不持有服务内部数组或其他页面的 LVGL 指针。

路由、输入与优先级

打开系统覆盖层时记录来源路由及 generation；同一覆盖层重复请求合并。普通 Back 关闭顶层并返回来源，Home 按 D09 语义回应用列表／表盘，不能穿透到已隐藏的页面。页面栈满、历史被驱逐或候选页创建失败时保留当前可用页面并给出可退出错误态。只有真实 ONSTART／ONSTOP 和绘制空闲后才回收字体、缩略图及回调。

输入优先级为恢复层 → 活动提醒 → 水锁／输入锁 → 其他系统覆盖层 → 普通 App。锁期间新提醒仍进入 D12 账本；解锁后按账本状态展示，不能因为覆盖层被挡而丢提醒。水锁和输入锁进入、退出都经 GUI owner 调用 D09 取消；驱动线程只采集边沿并唤醒。现有 IW_INPUT_LOCKED 没有实体解锁意图，C 阶段必须补上并测试，未补前不得开放无法退出的锁入口。

KEY2 单击打开控制中心，KEY1 双击打开切换器；仅在 NORMAL 上下文且当前路由允许时触发。KEY1 单击维持 Home。水锁使用 KEY1 超过既有解锁阈值并松开；短按、触摸和旋转均不穿透。表盘选择使用表盘上的明确触摸入口；没有实物旋钮时全部选择和取消仍可用触摸完成。通知与叠放的边缘滑动只在表盘页面识别，手势一旦因滚动、溢出或跨页取消，不在新页面续用。

布局和资源约束

390×450 面板沿用现有 ScreenFrame、Q0／Q1、减弱动效及字体 owner。普通独立命中区至少 56×56；固定顶栏 0…104，正文在有界视口内滚动，底部至少留 24 px。控制中心优先放已实现的亮度和水锁两项，不为凑满网格加假控制；通知最多显示可见的 2–3 卡并复用对象，智能叠放只构造当前及相邻卡片。切换器先用图标／名称，未验证快照预算前不分配全屏缩略图。

静态文案纳入正式字体清单并阻止缺字构建；图标采用项目自绘资源，不嵌入未获许可的原厂图。继续遵守 D07 的 TTF、位图字体、图片、main 和字形池预算。每页产出 Q0／Q1、正常／大字号、最长中文、空态、能力缺失和错误态的主机帧；主机帧与实屏状态分别标注，不把静态图当作板测。
