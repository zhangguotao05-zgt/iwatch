组件契约

gui_core/iw_components只依赖字体服务、主题和 LVGL，不调用时间、亮度或其他业务服务。五类组件使用同一受控对象类，父对象拥有子树；组件自身没有业务线程、定时器或订阅。只有 GUI 主循环推进75 ms按压效果，减弱动态效果时直接使用最终状态。

组件行为布局
ScreenFrame普通、纵向滚动、全屏；自动登记页面故障 owner。固定标题与内容视口分离。390×450；普通/滚动视口宽354，标题横向18、纵向24。全屏去除标题及边距。
ListRow默认、按下、禁用；标题、次级说明和右值。点击只发语义 action。最小行高60；双行按字体实际 line_height 校验，空间不足返回 INVALID。
PillButton正常、按下、等待、禁用、危险；等待显示省略号并阻止再次提交。高度固定60、圆角30；命中范围不随按压缩放变化。
StatePanel加载、空、错误、外部不可用；文案由 Presenter 提供，不改变占位尺寸。标题和说明使用明确字体角色，支持64/80/96数值；根据真实行高校验高度。
StatusBanner信息、成功、警告、危险，以静态色条和文案表达；自动消失和节流由后续 Presenter 管理。沿用主题表面、圆角、正文及次级颜色。

Q0/Q1共享几何与语义。Q0不透明，Q1按主题使用透明度和按下渐变；动画只改变绘制区域，命中区稳定。标题127字节、说明255字节、右值47字节，均为UTF-8有效载荷上限，不截断多字节字符。非法UTF-8、超长或不适用字段拒绝更新且保留旧状态。长文字限定在分配区域内绘制；需要更多正文时由页面提供更高的滚动内容区域。

view更新不分配文本、样式或字体，输入文案复制进对象内的固定缓冲。异步绘制任务另外保存文案快照，防止下一次更新改写在途任务；这部分仍有受控分配，不宣称整个绘制过程零分配。字体在构造时获取，字号和质量配置在对象存活期间固定。

为避开普通控件内部不可恢复的构造分配，组件使用固定几何属性表和自绘内容。对固定SDK私有结构的依赖集中在组件实现内，外部通过句柄和view操作，不直接设置LVGL样式或复制句柄。真实LVGL构造、对象树、事件、绘制任务和软件渲染纳入主机测试。

页面所有权与故障回收

iw_gui_owner使用最多8个页面节点，不申请堆内存。clock在启动前登记，ScreenFrame自动登记；普通组件必须位于ScreenFrame内容子树中。页面暂停后只要还持有字体，仍须保持登记。节点和组件句柄地址必须在页面存活期间稳定，父对象删除时自动清空句柄。

  1. 字体或组件绘制分配失败只锁存故障；回调不删除对象、不释放在途缓存。
  2. GUI主循环暂停提交新的页面绘制，等待GPU/LCD空闲。永久忙的期限与受控重启仍属D16。
  3. 取消输入，先摘除owner节点，再执行页面停止。ScreenFrame在删除子对象前调用quiesce，停止页面定时器和订阅；组件清除动作回调和动画，然后删除对象、释放字体引用。
  4. 全部owner均清理后，字体服务回收零引用字体。仍有未登记的违规引用时拒绝确认，不强行释放。
  5. 确认成功后显示预创建的内置字体应急层。Home隐藏全局应急层并按既有导航返回；诊断页的Home关闭请求在GUI安全点处理。

正常退出也必须使用组件销毁接口并等待渲染空闲；BUSY表示句柄仍存活，调用者应在后续安全点重试。不要在绘制回调内销毁对象，或绕开该契约直接删除仍在渲染的外层父对象。重复销毁空句柄成功。字体统计中的fallback计数表示显示了应急层，可能来自字体或组件绘制失败；具体故障来源需结合日志。

实机发现的组件退出延迟

初版 a7b4025 仅在 lv_timer_handler 之后检查组件邮箱并等待GPU/LCD空闲。底层表盘持续绘制时，下一轮又先发起绘制，关闭请求无法及时获得安全点；按键队列已消费不代表页面已经退出。

在初版板上用 app_run clock 后开关Q1复现。最后一条 iw_demo 0 于07:15:03.314061 UTC发出，包含关闭结果的串口块于07:15:06.901376 UTC收到，间隔约3.587秒。此前多个开关请求被诊断邮箱的最新请求覆盖，不能计为已执行轮次。证据见本地 logs/board-validation-20260917-d07-c/ 原始数据及带字节偏移的接收时间线；该归档保留为失败对照。

修正为绘制前、后都处理安全点：存在未处理的页面开关时暂停新的绘制，保留服务与输入处理，按1ms间隔等待在途GPU/LCD完成，再执行开关。没有请求时保持原刷新方式；不取消在途绘制，也不强行删除忙对象。新增测试直接提取生产诊断邮箱与GUI帧协调函数，使用真实组件和字体服务；1000轮开关、101,000次忙状态检查通过，等待期间无新增绘制提交、退出后无持续分配增长。该测试替换硬件时序，不替代实屏延迟复验。
