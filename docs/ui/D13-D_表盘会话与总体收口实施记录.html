D13-D 表盘会话与总体收口实施记录

2026-09-22 · Issue #15 · 设计基线 c7617c2 · 代码修正 a2e61fd · 实机证据基线 2892732 · 文档内容基线 8587d13 · 状态提交 b7d51aa · 当前状态：D13-D 架构复核通过，main 已推送；Issue #15 保持打开

本页把 D13 的剩余开发目标写成可执行的验收契约。它记录当前实现和证据边界，不提前宣称 D13 最终收口。代码注释、测试日志和工程文档按项目约定使用中文；外部 SDK 的原始注释不在本页改写。

产品目标

当前产品目标是一个 390×450、离线可运行的 Apple Watch 风格界面基线：表盘、蜂窝应用列表、控制中心、通知、智能叠放、最近 App、设置、计时器、闹钟和两种输入锁在同一套路由、输入仲裁和资源回收规则下工作。D13 只负责界面会话与覆盖层，不把联网、微信/支付宝、健康传感器算法或生产级 Apple 兼容性写入本阶段完成条件。

本阶段可交付目标

  1. 长按当前表盘约 700 ms 只触发一次表盘选择器，松手不会追加点击；选择器提供两个稳定 ID：DIGITAL=1、MODULAR_LOCAL=2。
  2. 编辑器以值复制方式维护草稿，支持强调色、中心信息、左侧快捷入口、右侧快捷入口四项配置；数字表盘不显示不可用的模块字段。
  3. 取消、返回、显示能力缺失、路由失败和 revision 冲突都保留原表盘配置；只有返回根页完成异步 ONRESUME、快照稳定且页面健康后才提交候选配置。
  4. 覆盖层、页面和字体继续使用既有 owner、固定节点和安全点回收规则，不为预览创建全屏缓存，不引入新的长期堆对象。
  5. 把目标、版本、镜像身份、测试分层和板测门槛写入仓库，架构师可以按同一基线独立复核。

表盘会话契约

阶段输入状态变化失败行为
进入表盘长按或编辑入口创建 face_draft，复制当前 session 和 expected_revision页面创建失败时保持当前表盘，显示已有应急层
字段编辑颜色、中心、左右快捷入口只修改草稿，不增加 session revision非法枚举值被拒绝，草稿保持上一个有效值
取消取消按钮、Back、Home 或覆盖层失效清空草稿和 pending 事务当前表盘配置、revision 和历史均不变
应用选择按钮检查显示能力和 expected_revision，建立 pending candidate，并登记待确认返回冲突或能力缺失显示“时间设置已变化”/“显示不可用”，留在编辑器
提交根页异步 ONRESUME、稳定快照、页面健康提交候选配置，revision 单调增加，清空 pending请求拒绝、异步失败、根页恢复失败、故障回收、超时或重复返回均回滚到 previous session

应用动作采用两阶段提交：控制器先保存 face_previous 和 face_pending，路由器只在根页异步 ONRESUME 完成并再次确认快照后调用 commit；提交成功后立即把新 session 同步到根页模型，保证返回表盘显示与控制器一致。路由拒绝、返回、能力竞态、故障回收和 3 秒未完成的异常转场调用 rollback。Home 与 Apply 同周期时，Home 先撤销候选和返回事务；超时使用独立的“计时已开始”标志，因此系统 tick 从 0 开始也会正确回滚。这样不会出现“画面没有切换但表盘已经改变”或 pending 跨页面残留的半提交状态。

实现与所有权

文件职责
src/gui_core/iw_product_scene.[ch]选择器、编辑器和表盘预览；固定节点、390×450 边界和可用字段布局。
src/gui_core/iw_product_view.[ch]长按识别、松手抑制和页面生命周期；不在输入回调中直接删除对象。
src/gui_core/iw_routes.c将 FACE_PICKER、FACE_EDITOR 注册为可用页面。
src/platform/iw_product_controller.[ch]session 默认值、枚举校验、草稿、revision 冲突和 pending 事务所有权。
src/platform/iw_router.c提交/回滚与根页异步生命周期绑定；请求失败、ONRESUME 失败、故障回收和超时不遗留半提交状态。

本阶段不改变 D13-C 的锁优先级和输入契约：水锁仍先屏蔽触摸和 KEY2，普通输入锁仍要求 KEY1 长按并真实松手。表盘编辑只在解锁后的普通路由上下文中工作。

COM9/COM10 实机复核

使用与 e324f14 身份归档绑定的 GCC 三件套，经 COM9 写入并校验；全程未访问 J-Link。COM10 原始日志保存在 work/d13d-board-e324/serial.raw，大小 28,798 字节，SHA-256 为 d9d2854aa2c0c0c49d02c86ec2c536194fb0019b8b0038cd65306e40db8303de。

  • 冷启动识别到 CO5300 显示控制器和 FT6146 触摸控制器；启动过程中没有 HardFault、断言、draw_core timeout 或 LCD timeout。预存的 flash1 is not found 仍属于 D15。

  • 取消编辑后返回表盘未产生提交确认；重复进入和返回没有遗留 pending。采样时输入队列为空，触摸统计为 overflow=0、queued=0、wait_release=0，字体字形池无持续增长。
  • 补验实际点击编辑器左侧“取消”按钮：COM10 原始日志记录 Clicked at 100,405，未出现 face commit confirmed root_onresume；随后回到 iwface/root，最终 state=0、current=0001:0、busy=0、pending=0。补验日志为 work/d13d-board-e324-cancel/serial.raw，大小 6,404 字节，SHA-256 为 ced6b3e63cf97cb0a82e10fba7e7d59825b616cddd5a40f28806a64ce01f8ff3。
