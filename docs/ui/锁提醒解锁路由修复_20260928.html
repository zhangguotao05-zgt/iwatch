基于公开 main 4e9c076（与 03ecd4b34924 同 tree），保留 D13 v2 的解锁后提醒可操作、账本不自动确认契约。旧板上观察为提醒→列表→同提醒快速切换；本次只改应用路由和受影响夹具，不改 SDK、按键协议、DMA／显示驱动、分区或资源。

实现与所有权

app_watch owner 接到解锁意图后保留前台提醒实例，先回收后台控制中心、再回收锁页；复用既有 gui_app_remove_page、三次有界重试、STOP 后安全释放事务。实例由指针＋generation 校验，原来源按 app 和名称绑定；清理完成前保持锁输入上下文，完成后重新读账本、更新原提醒并取消跨页残留输入，不加载来源中间屏幕。

不写 hidden_alert，不发 ACK／SNOOZE。提醒业务侧失效后退回来源；来源失效转入既有根页恢复，再按账本展示提醒，恢复不是用户隐藏动作。资源忙时不执行清理；失败耗尽保留锁与原提醒，新的有效长按释放才重新给有界预算。无提醒时沿用原解锁路径。只新增一个固定大小事务状态，无额外页面、图像或后台任务；目标大小以 GCC map 为准。

局部夹具 firmware/tests/control_router 使用真实 input_signal、生产路由、TARGET View、D12 服务与 LVGL 屏幕事件。新增 runtime_model 让路由、控制器和命令处理共用账本；只替换 RTOS 邮箱／调度与硬件边界。SCREEN_LOADED 事件证明软件没有加载来源屏幕，不等同于面板逐帧验收。
