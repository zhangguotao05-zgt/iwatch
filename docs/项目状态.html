在线已保存 PCB1 未布线准备稿，153 个器件/测试点位置、726 个焊盘网络与原理图模型一致。本地 epro 为原理图及封装库备份，PCB1 在在线工程中。默认双层 PCB 文档尚未冻结板层工艺。

下一阶段：锁定板框与电池/表冠/LRA/裸屏接口等实物参数，完成电源和阻容采购细节、ESD 方案、PCB 布局布线及制造审查。本资料不是可直接下单的 Gerber，也尚无实物测试结果。

2026-09-15 开发板进展：已在 SF32LB58-DevKit-LCD A128R32N1 实物上烧录并运行 SDK v2.5.1 watch_v9。实物芯片为 A1 修订版，官方 QSPI 板型默认的 LCPU_CONFIG_V2 会在启动阶段断言；HCPU、LCPU 板级配置改为 LCPU_CONFIG_AUTO 后启动正常。COM9 用于下载，COM10 为 1 Mbps HCPU 日志口。无屏状态下 RT-Thread、LVGL 和 Main 应用已运行，显示 ID 与触摸 I2C 错误等待屏幕到货后复测。

同日已将可修改的 watch_v9 应用源码、A128 QSPI/A1 板级修正和项目专用分区表迁入仓库的 firmware 目录。项目名称统一为 iwatch。M0 版本已完成 GCC 全量构建和 Keil 工程生成，Keil 工程包含 925 个有效源码引用；新分区和输入队列尚未烧录到开发板。

2026-09-11 后续设计输入：佩戴版拟改用亚特联 CWS05 / C50396528（390×450 QSPI AMOLED，CO5300AF + CST820）。新屏为24针、1.8V数字接口，不能直接接现版3.3V显示/触摸电源域；连接器与部分供电定义仍需确认。普通阻容优先评估英制0201，复位/下载直插键改为测试接点，Home/唤醒功能计划并入表冠按压。上述内容仍处于修订评估阶段，尚未同步到v0.3在线电路。
